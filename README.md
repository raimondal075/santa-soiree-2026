**🎅 Santa Soirée 2026 – Event Management Website**
 📌 **About the Project**
Santa Soirée 2026 is a colourful and interactive event management website created for the Department of CSE AIML. It provides information about the event, its objectives, schedule, faculty coordinators, and different student competitions.

 🎯 **Objectives**
- Encourage creativity, teamwork, and innovation.
- Provide a platform for coding, gaming, graphic design, and innovative projects.
- Allow students to explore different events and fill out registration forms.
- Display a live countdown to the celebration.

 🎉 **Events**
1. 💻 **FrostByte** – Hackathon and Coding Challenge
2. 🎮 **SnowKing** – Gaming Championship
3. 🎨 **Aurora ArtFest** – Graphics and Creative Design
4. 🚀 **Reindeer Innovation Lab** – Innovative Projects and Models

 📅 Event Details
- **Date:** 20 December 2026
- **Time:** 10:00 AM – 8:00 PM
- **Venue:** Genesis Building
- **Department:** CSE AIML

 👨‍🏫**Faculty Details**
- **HOD:** Dr. Amartya Sengupta
- **Faculty Coordinators:** Prof. Piyali Mukherjee 
- **Event Lead**: Prof. Vivekananda Kundu
 🛠️ Technologies Used
- HTML – Website structure
- CSS – Styling, layout, gradients, and animations
- JavaScript – Countdown timer and interactive registration forms

 **✨ Features**
- Attractive neon-gradient design
- Animated snowfall effect
- Live countdown timer
- Four event cards with separate registration forms
- Event schedule and faculty details
- Responsive layout for desktop and mobile
- Print / Save as PDF option

 ▶️ How to Run
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Explore the events and test the registration forms.
